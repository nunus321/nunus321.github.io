




## *Runeweaver*
## 2026

### • 2D Game Dev, Gesture Recognition,
### • Cross-Platform
Runeweaver is a 2D fantasy game project I solo developed with a focus on gameplay systems
and live gesture recognition. A core mechanic of the game is rune drawing: unlike more
conventional games, where abilities are triggered through fixed buttons or hotkeys, the
player draws symbols directly on the screen, and those symbols are recognized in real time
and translated into gameplay actions.

For example, a zigzag-shaped rune is recognized and turned into a lightning attack, firing
a beam in the direction the player is aiming. A different rune, shaped like a fork, creates
a shield that can be used to deflect incoming enemy projectiles.

The game also supports both PC and touch devices, with controls that adapt automatically
to the platform so touch controls only appear when relevant. It has been tested on Windows,
Mac, and iPhone.
