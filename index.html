Runeweaver

2026

  • 2D Game Dev
  • Gesture Recognition
  • Cross-Platform

Runeweaver is a 2D fantasy game project I solo developed with a focus on gameplay systems and live gesture recognition. A core mechanic of the game is rune drawing: unlike more conventional games, where abilities are triggered through fixed buttons or hotkeys, the player draws symbols directly on the screen, and those symbols are recognized in real time and translated into gameplay actions.

For example, a zigzag-shaped rune is recognized and turned into a lightning attack, firing a beam in the direction the player is aiming. A different rune, shaped like a fork, creates a shield that can be used to deflect incoming enemy projectiles.

The game also supports both PC and touch devices, with controls that adapt automatically to the platform so touch controls only appear when relevant. It has been tested on Windows, Mac, and iPhone.

Playable demo: https://jonasalmersaloutlookdk.itch.io/runeweaver

Pokedex website: Pokemon index

  • CRUD
  • HTML

This Pokedex web app is a small project I built to practise full-stack Python and the use of SQL databases. When you open the web app, all 151 original Pokemon load in a flexible card grid that works well on phones and desktops, letting you scroll through the list quickly. Clicking a card takes you to a page that shows the Pokemon's picture, type, stats, height and weight, straight from a tidy SQLite database. Math Toolkit

I developed this lightweight desktop web application to help Danish primary- and secondary-school students explore mathematics visually instead of just on paper. The app has a function plotter where you can type any equation (for example 2*x^2 – 3) and see the graph appear instantly. In addition it has four sliders that let you stretch, compress, or shift the curve along the x- and y-axes, so students can watch in real time how each change affects the shape of the function. Breakout Arcade Game

2024

  • C#
  • Game Dev
  • NUnit testing
  • Parsing

This project is a modern Breakout-style arcade game written in C#, produced as the capstone for my Software Development course at the University of Copenhagen. Its architecture follows SOLID principles, using a singleton event-bus mediator and a dedicated state machine to keep menus, pause, and gameplay modules cleanly separated. Levels load from simple text files that our custom parser converts on the fly, letting anyone design stages of up to 288 blocks without touching the code. Special blocks can drop random power-ups or hazards, adding an extra layer of strategy and replay value. The codebase is fully unit-tested with NUnit and extensively play-tested for reliability; watch the gameplay video and explore the open-source repository on GitHub. Blood-Alcohol Estimator App

2022

  • C#
  • Unity
  • UI/UX
  • Mobile App dev

For my final year at Danish gymnasium I developed a mobile application that estimates a user’s blood-alcohol content (BAC) with nothing more than the phone in their pocket. After a brief set-up where the user enters weight and biological sex, the app calculates BAC in real time each time a drink is added, relying on the official equations published by the Danish national health portal, Sundhed.dk.

It also explains the typical side-effects at different BAC levels, indicates when it is unsafe to drive, keeps daily and weekly consumption statistics and even shows a countdown to the point at which the user is expected to be sober again. The project gave me hands-on experience with mobile UI design, data validation and the challenge of translating clinical formulas into efficient, user-friendly code

Fake-News Detector

2025

  • Machine Learning
  • Deep Learning
  • NUnit testing
  • Neural Network
  • Python
  • Naive Bayes
  • Support-Vector Machine
  • Random Forest

I designed and trained a full natural-language-processing pipeline that can tell whether an online news article is fake or reliable. After cleaning and organising a large collection of stories, I trained several well-established machine-learning models including: Naive Bayes, logistic regression, Random Forest, Support-Vector Machine, and a neural network and selected the model that performed best. The final system gets the answer right more than 96 % of the time on unseen articles. To keep the results transparent, I built a dashboard that highlights the words in each story that raised a red flag, so anyone can see why the program reached its decision. By applying these complex mathematical models, the detector uncovers patterns in language that humans would be very unlikely to spot on their own, making it a powerful aid in the fight against misinformation.

Bachelor's Project: AI for Reranking

2026 – Present

  • Python
  • Machine Learning
  • AI
  • Data Processing
  • Information Retrieval

For my bachelor's project I am working on learning-to-rank on the Amazon ESCI dataset, where each example contains a search query together with candidate products. The goal is to train models that improve the ordering of products in search results. One of the core challenges is that the space of possible pipelines — which fields to include, which preprocessing steps to apply, and in what order — is far too large to test exhaustively. To tackle this I use the ASHA algorithm (Asynchronous Successive Halving), which intelligently allocates compute budget by quickly discarding poor configurations early and concentrating resources on the most promising ones. This makes it feasible to search a very large pipeline space and still find a strong setup. Beyond the search itself, the project covers everything from data cleaning and feature engineering to model selection and evaluation, with the goal of surfacing the most relevant results at the top of every query.
